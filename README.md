# Omnicommerce Data Migration Project

## Project Overview
This project focuses on migrating an e-commerce data warehouse from Google BigQuery to the Databricks Lakehouse platform.

## Source Platform
- Google BigQuery (GCP)

## Target Platform
- Databricks Lakehouse

## Project Objectives
- Migrate data from BigQuery to Databricks.
- Use Google Cloud Storage (GCS) for data transfer.
- Build a scalable data migration workflow.
- Validate migrated data.

## Project Status
Currently in Progress.
